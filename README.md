## 📋 Описание

**Трекер Привычек** — это современное Telegram Mini App для отслеживания привычек с учетом контекста. Приложение позволяет создавать привычки, привязывать их к различным контекстам (места, время, активности) и отслеживать прогресс.

### 🎯 Основная концепция

В отличие от обычных трекеров привычек, это приложение учитывает **контекст** выполнения:
- 🏠 **Места**: дом, офис, спортзал, парк и др.
- ⏰ **Время**: утром, вечером, выходные
- 🎯 **Активности**: работа, учеба, путешествие

Это позволяет создавать более гибкие и реалистичные привычки, например:
- 💧 "Пить воду" — дома, в офисе, в спортзале
- 📚 "Читать книги" — утром, вечером, в транспорте
- 🧘 "Медитировать" — дома, в парке, перед сном

## 📦 Установка

### Требования
- Node.js 18+ 
- npm или yarn
- Telegram аккаунт (для тестирования в Telegram)

### Шаги установки

1. **Клонируйте репозиторий** (или скачайте проект):
```bash
git clone <your-repo-url>
cd my-telegram-app
```

2. **Установите зависимости**:
```bash
npm install
```

3. **Запустите dev-сервер**:
```bash
npm run dev
```

4. **Откройте в браузере**:
```
http://localhost:5173
```

### 🔧 Настройка для доступа с телефона

Для тестирования на реальном устройстве через локальную сеть:

1. Убедитесь, что `vite.config.js` настроен на `host: '0.0.0.0'`
2. Запустите сервер: `npm run dev`
3. Найдите IP адрес Mac: `ifconfig | grep "inet "`
4. Откройте на телефоне: `http://YOUR_IP:5173`
5. Убедитесь, что телефон и Mac в одной Wi-Fi сети

## 🚀 Использование

### Создание привычки

1. Нажмите кнопку **"Добавить привычку"**
2. Заполните форму:
   - 📝 Введите название (обязательно)
   - 📄 Добавьте описание (необязательно)
   - 🎨 Выберите иконку и цвет
   - 📍 Выберите контексты (минимум 1)
   - ⏰ Установите частоту выполнения
   - 🎯 Укажите цель (количество раз)
3. Нажмите **"Создать привычку"**

### Управление привычками

- 👆 **Нажмите на карточку** — просмотр деталей
- 🗑️ **Нажмите корзину** — удаление привычки
- ✅ **Активные привычки** — отображаются в основном списке

### Контексты

Привычки можно привязать к контекстам:
- **Места**: дом, офис, спортзал, парк, кафе, магазин, больница, школа
- **Время**: утром, вечером, выходные
- **Активности**: работа, учеба, путешествие
